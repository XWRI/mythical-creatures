# 山海经图鉴 · 南山经原型

纯静态页面，没有构建步骤。

```bash
python -m http.server 8731
```

然后打开 http://127.0.0.1:8731/ 。直接双击 `index.html` 也可以打开（数据是 `.js`，不需要 fetch）。

## 文件

- `data/nanshan.js`：南山经 3 列山系、39 座山的结构化数据，包括原文、自译白话、方位里程、有名物产（附功效原文、现代说法和标签）以及泛指物产。
- `app.js`：按“又东某百里”推算出原文拓扑图（SVG，可拖拽、可缩放），右侧是详情面板，上方是功效反查。
- `style.css`：古籍纸色主题，带暗色模式。

## 待办

- 原文是凭通行本录入的，**还没有逐字校对**，生僻字（𪊨、𨏖、䳋 等）要对照影印本核实。
- 原文条目与总结句对不上（首经 9/10 山、次三经 13/14 山），页面上有标注。
- 白话是本项目自己翻译的；不要换成现代出版物的译文，那些有版权。
- 插图（`data/illustrations.js`）：南山经有名物产中 22 种配了图，另有一张首经山神图，共 38 张，全部是 Wikimedia Commons 上的公版刻本，来自三个版本：蒋应镐本、胡文焕本（Commons 上的矢量描摹）和汪绂本。图片已下载到 `assets/illustrations/`（480px 宽），由 `python tools/fetch_illustrations.py` 生成；新增插图后重跑一次即可，已有的文件会跳过。页面上点图会跳到 Commons 原页，保留出处。
- 还没有图的：育沛、鮆鱼、虎蛟、鱄鱼、白䓘、鹓雏、迷穀以外的草木。可以去 Commons 上的整本扫描 PDF（如 `山海經十八卷 蔣應鎬繪圖 明萬曆間刊本.pdf`）里裁图补齐。
